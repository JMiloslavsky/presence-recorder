# Формат `.presence` (версия 2)

## Назначение

Формат описывает запись 6DoF-присутствия: положение и поворот головы
и двух рук во времени. Читаем человеком, парсится любым JSON-парсером.

## Поля верхнего уровня

| Поле | Тип | Описание |
|------|-----|----------|
| `version` | int | Версия формата (сейчас `2`) |
| `created_at` | string | ISO-8601 время создания записи |
| `fps` | int | Целевая частота кадров (справочно) |
| `frames` | array | Массив кадров |

## Кадр

| Поле | Тип | Описание |
|------|-----|----------|
| `t` | float | Время от начала записи, сек |
| `h` | object | Голова: `{p, r}` |
| `l` | object | Левая рука: `{p, r}` |
| `r` | object | Правая рука: `{p, r}` |

`p` — `[x, y, z]` в метрах, `r` — `[x, y, z]` эйлеровы углы в радианах.

## Совместимость

- v1: только `h` (голова). Парсер должен обрабатывать отсутствие `l`/`r`.
- v2: `h`, `l`, `r`.

## Планы

- v3: кватернионы (`q` вместо `r`).
- v3: якоря сцены (`anchors`).
- v3: мимика (`blendshapes`).
