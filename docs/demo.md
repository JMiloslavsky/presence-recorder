# Как пережить чужой полёт за 60 секунд

## Без VR (только Godot)
1. Клонируй репозиторий.
2. Открой `project.godot` в Godot 4.2+.
3. Нажми F5 — запустится `scenes/main.tscn`.
4. Нажми F9 — загрузится `examples/demo_flight.json`, призрак полетит.
5. Наслаждайся. Это и есть «кассета присутствия».

## С VR
1. Установи Godot XR Tools в `addons/`.
2. Открой `scenes/main.tscn`.
3. Надень шлем, запусти.
4. Нажми F9 — призрак полетит в VR-пространстве.
5. Ты можешь лететь рядом и смотреть со стороны.

## Что ты только что сделал
Ты загрузил файл, в котором записано чужое присутствие, и пережил его
в 3D-пространстве. Это не видео. Это 6DoF-трек, привязанный ко времени,
с интерполяцией. Формат `.presence` открыт — любой может создать свою кассету.
